# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1, whose full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be welcoming, be kind, assume good faith, and keep criticism about the work. No
harassment, insults or personal attacks, in public or private, in any space of this
project: issues, pull requests, discussions and reviews.

## Reporting

If someone's behaviour is unacceptable, or you are unsure, tell the maintainer privately,
through the contact details on the repository owner's GitHub profile. Reports are handled
in confidence. The maintainer may remove, edit or reject contributions that break this
code, and may ban anyone who breaks it repeatedly or seriously, following the Contributor
Covenant's enforcement guidelines.
